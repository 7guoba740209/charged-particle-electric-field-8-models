偏转04

中点结论

见到“射出偏转电场的速度方向” → 反向延长线过板长中点。
tanθ / tanα = —

核心结论

1
速度方向：tanθ = vyv0 = atv0
2
位移方向：tanα = yL = at2v0
3
tanθ = 2tanα → 反向延长线交于 L/2 处
教师点拨：这不是新物理，是抛物线的几何性质：切线斜率恰为割线斜率的两倍。它是模型 06 的钥匙——凡“出场后打到屏上”，都可等效为“从板中点沿直线射出”。

交变电场07

交变电场

见到“方波电压、t = 0 静止释放” → 画 v-t 图，速度不变号就一直向前。
每半周期位移 s —

核心结论

1
a = qUmd，每半周期加速度反向、大小不变
2
vmax = aT/2，每周期末 v = 0（v-t 为三角波）
3
每半周期位移均为 s = aT28
教师点拨：网上常写位移比“1∶3∶5”，那是单向匀加速连续相等时间的比，用在这里是错的——此处速度减到零再加速，四个半周期位移相等。若释放时刻改成 t = T/4，速度就会反向，粒子原地往复。
等效场08

等效重力场

见到“重力与电场力都是恒力” → 合成等效重力，找等效最高点。
g′ = —

核心结论

1
mg′ = √[(mg)2 + (qE)2]，　g′ = √[g2 + (qE/m)2]
2
等效最低点为平衡位置，正对面是等效最高点
3
恰好过顶：mg′ = mv2/L → vmin = √(g′L)
4
绳模型最低点：v = √(5g′L)；杆模型过顶可为 0
教师点拨：把单摆、圆周运动的所有公式照搬，只需 g → g′、把“竖直方向”换成“合力方向”。判断“能否完成圆周”，关键不是几何最高点，而是等效最高点——此处速度最小、绳子最先松弛。
